How to install
  1. Click Copy link on the script you want.
  2. Open the Tampermonkey Dashboard from the extension menu.
  3. Go to Utilities, paste the link into Install from URL, and click Install.
  4. Review the script on the screen Tampermonkey shows, then confirm the install.
